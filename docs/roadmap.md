# Roadmap

## Phase 0 — Foundation and mock vertical slice

- Layered projects and dependency direction
- Generic customer, purchase, voucher, and activity concepts
- Semantic catalog and mock data source
- Audience builder and preview API
- Tests, security exclusions, and discovery documentation

## Phase 0.5 — Validated analysis foundation (current)

- Document two sanitized, historically delivered use cases
- Share filter and semantic primitives between Audience and Analysis
- Add capability metadata and metric definitions to the semantic catalog
- Deliver the mock UC002 monthly analysis and spending distribution
- Establish validated-query review and knowledge-promotion rules

## Phase 1 — Confirmed customer and purchase semantics

- Perform company data discovery
- Record identity, transaction, date, amount, brand, return, and currency rules
- Approve a minimal semantic model without exposing physical names to the UI

## Phase 2 — Audience builder and engine depth

- Nested visual groups and complete operator editors
- Better validation and null semantics
- Segment explainability and query preview diagnostics

## Phase 3 — Oracle adapter and company mapping

- Implement mappings only from confirmed discovery evidence
- Add safe configuration, parameterization, query limits, and integration tests
- Keep all Oracle-specific behavior in Infrastructure

## Phase 4 — Customer 360

- Customer profile and timeline based on confirmed semantics

## Phase 5 — Saved segments

- Persistence, naming, versioning, ownership, and change history

## Phase 6 — Excel export

- Explicit export fields, limits, classification, and safe local handling

## Phase 7 — Security, audit, and performance hardening

- Authentication/authorization, audit events, PII controls, query budgets, monitoring, and retention

## Phase 8 — Reassess AI

- Evaluate AI only after semantic correctness, governance, and deterministic workflows are established
